# Black Label Portfolio

Portfolio React + Vite dengan palet hitam, merah, dan emas.

## Menjalankan lokal
1. Ekstrak folder ini.
2. Buka folder proyek di VS Code.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.

## Foto profil
Taruh foto di `public/profile.jpg`. Jika nama atau format fotonya berbeda, ubah `src="/profile.jpg"` pada `src/main.jsx`.

## Sebelum dipublikasikan
Ganti tautan GitHub/LinkedIn/Instagram dan `your.email@example.com` dengan milikmu. Periksa kembali detail pengalaman, proyek, pencapaian, dan pendidikan.

## Deploy ke Vercel
Import repository ke Vercel. Framework akan terdeteksi sebagai Vite; build command `npm run build`, output directory `dist`.
